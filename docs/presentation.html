📋

إدارة الحجوزات

صفحة كاملة لإدارة جميع الحجوزات:

  • • تبويبات حسب الحالة (الكل، مؤكدة، بانتظار الدفع، نشطة، مكتملة، ملغاة)
  • • جدول تفاعلي مع بحث فوري
  • • عرض رقم الحجز، العميل، الكرفان، التاريخ، الحالة، المبلغ
  • • أزرار عرض وتعديل لكل حجز
  • • تصدير البيانات + pagination
  • • 4 بطاقات ملخص (إجمالي اليوم، بانتظار، نشطة، إيرادات)
🚐

إدارة الكرفانات

عرض وإدارة أسطول الكرفانات:

  • • عرض بطاقات مع صور وحالة كل كرفان
  • • فلتر بالحالة (نشط، صيانة، بانتظار الموافقة)
  • • إحصائيات: السعر، عدد الحجوزات، الإيرادات لكل كرفان
  • • معلومات المالك والموقع والتقييم
  • • أزرار عرض وتعديل
  • • زر "إضافة كرفان" جديد
📊

التحليلات والتقارير

رسوم بيانية وتقارير شاملة:

  • • إيرادات vs مصروفات (Area Chart مزدوج)
  • • توزيع أنواع الكرفانات (Pie Chart)
  • • أداء المناطق (Bar Chart أفقي)
  • • معدل الإشغال أسبوعياً (Line Chart)
  • • جدول أفضل الكرفانات أداءً
  • • 4 KPIs: إجمالي الإيرادات، الحجوزات، المستخدمين، التقييم
